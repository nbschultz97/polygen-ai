## Product Hunt Submission

### Tagline (60 chars max)
```
Turn words into 3D-printable models with AI
```

### Short Description (260 chars)
```
PolyGen AI transforms text descriptions into printable OpenSCAD code using multi-agent AI (Gemini + Claude). Describe what you want, get parametric 3D models you can edit and print. Free tier available with 5 generations/month.
```

### First Comment (From Maker)

```markdown
Hey Product Hunt!

I'm Noah, the solo founder behind PolyGen AI. As someone who's been 3D printing for years, I was always frustrated by the learning curve of CAD software. I wanted to just *describe* what I needed and get printable code.

So I built PolyGen AI - it uses a multi-agent pipeline where:
1. **Gemini** plans the geometric structure
2. **Claude** generates the OpenSCAD code
3. **Browser WASM** validates everything instantly

What makes it different:
- **Parametric output** - Not mesh files, but editable code you control
- **OpenSCAD format** - Works with the open-source ecosystem
- **Image-to-3D** - Upload a photo, get a 3D recreation
- **100% in browser** - No server-side rendering, your designs stay private

We're giving everyone **5 free generations/month** to try it out.

I'd love your feedback! What would you want to create first?
```
